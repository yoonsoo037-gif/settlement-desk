# 정산 데스크

정산 원본 엑셀을 올리면 공급가액·부가세·총액, 검토본 엑셀, 품의 입력 내용, ERP 업로드 파일을 만드는 개인 정산 도구입니다.

**이 저장소에는 회사 데이터가 없습니다.** 화면 코드(`docs/`)와 Google Apps Script 코드 사본(`apps-script/`)만 있습니다.
매핑·이력·검증 기준 금액·ERP 코드·거래처 정보 같은 기준 데이터는 비공개 구글시트에만 있고, 비밀번호를 확인한
Apps Script를 통해서만 내려옵니다. 업로드한 엑셀은 브라우저 안에서만 처리되고 어디에도 전송되지 않습니다.

## 구조

```
docs/
  index.html         ← 첫 화면 (트랙 목록)
  config.js          ← 서버(Apps Script 웹 앱) 주소만 둠
  truz/index.html    ← TRUZ 트랙 (정산 / 품의 복붙 / ERP 전표 3탭)
apps-script/
  Code.gs            ← 백엔드 코드 사본 (실제 배포는 회사 구글 계정에서)
```

GitHub Pages가 `main` 브랜치의 `docs/` 폴더를 서빙합니다.

## 트랙 추가 규칙

1. `docs/<트랙>/index.html` 화면 추가, 첫 화면(`docs/index.html`)에 카드 추가
2. DB 시트에 `<트랙코드>_매핑 / _이력 / _확정 / _설정` 탭 추가
3. `apps-script/Code.gs`의 `TRACKS`에 한 줄 추가 후 재배포(배포 관리 → 수정 → 새 버전)

## 공개 저장소 원칙

금액·요율·코드·거래처·담당자 연락처·문서번호는 커밋하지 않습니다. 모두 비공개 시트의 `_설정` 탭에 둡니다.
